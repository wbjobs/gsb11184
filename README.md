# 标签页广播确认工具

一个纯前端小工具：任意标签页发送广播消息，其他标签页收到后自动回复确认（ACK），
发送方实时统计 **已确认 / 未确认 / 超时** 并用 Canvas 可视化每个标签页的确认状态。

## 运行

```bash
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000 ，多开几个标签页即可
```

（直接双击 `index.html` 用 file:// 打开也可以，BroadcastChannel 在同源文件间同样生效。）

## 功能

- **广播 + 确认**：任意标签页都可当发送方；接收方自动回 ACK（幂等，重复消息重复确认）。
- **动态标签页**：1s 心跳 + 3.5s 过期，标签页开关后在线列表与期望确认集合自动收缩/扩展。
- **超时重发**：4s 未确认记为超时并自动重发，最多 3 次；补确认后超时状态消除。
- **乱序防护**：每个发送方维护单调递增序号，过期序号消息直接忽略，不覆盖已有状态。
- **发送方关闭**：其他标签页仅观察到其离线，页面不受影响。
- **刷新一致**：tabId 存 sessionStorage，在途消息与最近接收存 IndexedDB；
  发送方刷新后广播 `sync-request` 重新收集确认，接收方刷新后主动补发 ACK。
- **可视化**：Canvas 圆点实时展示每个期望确认标签页的状态（绿=已确认，橙=等待中，红=已超时）。

## 测试辅助

- 接收区勾选 **模拟确认丢失**：收到消息不回 ACK，用于验证超时重发。
- **注入乱序消息** 按钮：重发一条过期序号消息，验证接收方不误判。
